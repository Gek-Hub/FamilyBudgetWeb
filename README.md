# FamilyBudgetWeb

Веб-приложение на Django для учета и управления семейным бюджетом.

## Основные возможности

- регистрация и вход в семейный аккаунт;
- разделение данных по семьям;
- добавление членов семьи;
- учет доходов и расходов;
- категории доходов и расходов;
- счета и валюты;
- бюджетные лимиты;
- аналитика по категориям и членам семьи;
- AI-помощник для добавления операций текстом или голосом;
- хеширование паролей;

## Запуск проекта

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver 127.0.0.1:8010
```

Или просто открыть файл start_server_8010.bat

После запуска открыть:

```text
http://127.0.0.1:8010
```

## Демонстрационные семьи

```text
Поттеровы / 1234
Ивановы / 1234
Османовы / 1234
```

## DeepSeek API

Для работы AI-помощника можно добавить API-ключ DeepSeek:

```powershell
setx DEEPSEEK_API_KEY "your_key_here"
```

После этого нужно перезапустить терминал и сервер Django.

Если ключ не задан, приложение использует локальный простой разбор команд.
